# SentinelOps Dashboard

A lightweight, glassy, operator‑grade dashboard built with **React + Vite**.
This project provides a clean foundation for internal tooling, admin panels, and SOC/ops workflows.

## 🚀 Tech Stack
- React 18
- Vite 5
- ESLint + Prettier
- Modern CSS (glassy UI panels, gradients, responsive layout)

## 🧞 Scripts
- `npm run dev` — start development server
- `npm run build` — build for production
- `npm run preview` — preview production build
- `npm run lint` — run ESLint
- `npm run format` — run Prettier

## 📦 Installation
npm install
npm run dev
